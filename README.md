# Social Villagers

**Social Villagers** is a free Minecraft Bedrock add-on (26.30) with villager news style reactions, dance, party and emotions. FleetMCStudio. mcpedl pack. Enable both RP and BP.

## How to use
1. Download v1.1.0.
2. Extract `SocialVillagers.zip`.
3. Import `Social Villagers.mcaddon` into Bedrock (notes in `files/pack/`).
4. Enable the resource pack and the behavior pack.
5. Load a world.

## FAQ

**Java?**
This zip is Bedrock. Java notes stay in `files/notes/`.

**No valid zip on PE?**
Import the .mcaddon, not a loose folder. Enable RP and BP.

**Marketplace?**
This is the free FleetMCStudio pack, not the paid Villager News listing.

## Requirements
Minecraft Bedrock 26.30. Android, iOS, Windows 10/11.
